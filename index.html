Avatar Addon — 2.0.0 Overhaul

A scripting-driven Minecraft Bedrock addon that turns the Avatar: The Last Airbender bending system into a full survival gameplay layer — four elements, the Avatar and Dark Avatar states, a level-based skill tree, bending armour, and a server-side admin panel.

Behavior Pack + Resource Pack Version 2.0.0 88 Bendable Moves Min Engine 1.21.60

01Introduction

About the addon

Avatar Addon is a Minecraft Bedrock scripting addon that implements the four-element bending system from Avatar: The Last Airbender as a playable survival mechanic. Players choose an element (or start as a nonbender), bind moves to their hotbar, and progress through a skill tree by using their bending in combat and traversal. The 2.0.0 Overhaul update is a broad rework of the addon's combat, progression and admin systems.

Features overview

Four elements + two special paths

Air, Water, Earth and Fire, each with a dedicated moveset, plus a Nonbender chi-blocking kit and an end-game Avatar / Dark Avatar path that combines all four elements.

88 unique moves

Every move has its own cost, cooldown, damage tier and unlock requirement — from basic elemental shots to ultimate, once-every-few-minutes techniques.

Skill tree progression

A branching per-element skill tree unlocks passive perks and advanced moves as players level up their bending from 1 to 100.

Bending armour sets

Element-themed diamond-tier armour, craftable per element, that heals the wearer instead of taking damage from other players when worn as a complete set.

Full admin control panel

A UI-driven scroll (book/menu system) for editing world rules, per-player settings, world presets, move bans, and no-bending zones without commands.

Movesets & slot binding

Players bind moves to hotbar slots with configurable activation bindings, and can save/load whole movesets to switch loadouts quickly.

Installation requirements

  • Both the Behavior Pack and Resource Pack must be applied to the world — the addon will not function correctly with only one installed.
  • The world must have Beta APIs (experimental scripting) enabled, since the addon runs entirely on the @minecraft/server scripting API rather than vanilla commands.
  • After installing, an operator should run /function op once to receive the staff tag required to open the admin menu.

02Getting Started

Choosing your element

On first spawn, players open the Choose Bending Style menu to pick Air, Water, Earth, Fire, or Nonbender. Two world settings change how this works:

  • Bending Choice Final — once toggled on, a player's element choice is locked in permanently.
  • Bending Choice Random — assigns a random element automatically instead of letting the player pick.

If the Avatar path is enabled for the server (Avatar Publicly Selectable), a player who becomes the Avatar additionally chooses a starting element; the remaining three elements are then unlocked in the traditional cycle order (Air → Water → Earth → Fire) as they progress.

Becoming a bender

Choosing an element immediately grants that element's base moveset at level 1. From there, bending level rises through use (see Progression System), unlocking further moves and skill tree perks. The Avatar State itself only becomes available at level 75, and is a distinct on/off ability rather than a permanently active form unless the server enables Avatar State Permanent Duration.

Non-bender gameplay

Players who don't choose an element (or whose server has bending disabled) play as Nonbenders. Nonbenders are not left without tools: they get a small, distinct kit of four moves built around chi-blocking rather than elemental force — reflecting bending damage back at attackers, a plain dash, a short-range time-rewind that undoes recent damage, and detection of invisible entities. See Nonbenders in the Bending System section for the full list.

Controls & menus

Choose Slots

Bind a move to a hotbar slot (1–9): pick a move in the first column, then pick a slot in the second column. Whatever action you configure for that slot (the "binding") will trigger the bound move while that slot is selected.

Movesets

Save your current slot bindings as a named moveset and reload it later. Useful for keeping a "traveling" set of mobility moves and a separate "combat" set without re-binding every slot by hand.

05Progression System

XP & Levels

Bending level runs from 1 to 100 and increases through use — landing hits, using moves, and staying in combat all feed level progress. Two admin-configurable multipliers control the pace server-wide:

  • Bending Level Speed — multiplier on how fast players gain bending levels (default 1.0).
  • Bending Speed — multiplier on chi regeneration per tick (default 1.0).

Skill trees

Each element has its own branching skill tree of passive perks and unlockable moves (for example, Air's tree branches from a Core node through Warrior's Spirit, Chi Infusion, Twinkle Toes and Airflow branches, ending in leaf perks like Redirection, Wind Dash, or Air Spirit). Some perks apply passive gameplay changes directly, such as disabling fall damage or hunger, or turning off mob aggro.

Admins can toggle Skill Tree Fully Unlockable to let players unlock every node regardless of level, which is also what the built-in Combat Features world preset does automatically for everyone on the server.

Unlocking abilities

Most moves unlock by progressing through the relevant element's skill tree. A handful of high-level techniques unlock purely by bending level instead — this is how the Avatar's Supercharged moves and the Dark Avatar's signature techniques are gated:

Mastery

The Avatar State itself is unlocked as a distinct skill_required gate (avatar_state) at level 75, and its duration scales between the server's configured minimum (at level 75) and maximum (at level 100) unless Avatar State Permanent Duration is enabled, in which case it no longer expires on its own. Servers can also enable an Avatar State Resurrection effect with its own cooldown, acting as a totem-style save while the Avatar State is active.

06Armour & Equipment

Bending armour

Each of the four core elements has a full diamond-tier armour set (helmet, chestplate, leggings, boots) themed to that element. Wearing a complete set of four pieces from the same bending-armour namespace grants a powerful defensive effect: incoming player damage (excluding magic-type damage) is fully absorbed and converted into healing instead, along with a block sound and particle effect. Mixing bending armour with any vanilla or unrelated piece breaks the set bonus.

Crafting recipes

Every bending armour piece is crafted at a crafting table from its matching vanilla diamond armour piece plus element-flavoured materials:

For example, the Earth Helmet uses a shaped recipe of Obsidian around a Diamond Helmet. An Airbender's Glider item also has its own dedicated crafting recipe.

Effects

  • Full-set healing reflect — the headline bending armour effect described above.
  • The effect only triggers against damage dealt by another player, and is bypassed by magic-type damage.

Adding new moves

Every move file exports a single move object with a consistent shape:

const move = {
    name: { translate: 'elements.<element>.moves.<key>.name' },
    description: { translate: 'elements.<element>.moves.<key>.description' },

    cost: 25,          // chi cost
    cooldown: 10,       // seconds
    type: 'standard',   // standard | duration | charge | dragon
    id: 29,             // unique numeric id across the whole addon

    tier: 'HEAVY',      // key into DAMAGE_TIERS
    damage: {
        base: DAMAGE_TIERS.HEAVY,
        multiplied: 0
    },

    // optional gating, used mainly by Avatar / Dark Avatar moves:
    // level_required: 70,
    // skill_required: 'avatar_state',

    activate(player, PLAYER_DATA) {
        // move logic: particles, entity queries, applyBendingDamage, etc.
    }
}

export default move;

New moves are registered by importing them into the relevant <element>.js file's moves array, and adding matching name/description keys to en_US.lang (and any other supported languages).

Adding elements

An element is defined the same way dark_avatar.js composes borrowed moves from other elements alongside its own: an object with name, description, breakdown, color, icon, a chiCode/chiCodeOverflow pair, a moves array, a skillTree, and a runtime function called every tick. New elements are then registered in core/elements/import.js.

Custom components

Bending armour relies on standard minecraft:equippable item components plus a namespace check (pv:) done in script rather than a custom vanilla component — see core/events/entityHurt.js's isWieldingDensityOrBreachWeapon-style helper pattern for how full four-piece sets are detected each hit.

09Troubleshooting

Common errors

Admin menu won't open

Run /function op as the player who needs access. This grants the staff tag the menu checks for; without it, the addon shows a "no permission" message.

Missing textures, particles, or UI

Confirm both the Behavior Pack and Resource Pack are applied — installing only one is the most common cause of missing bending particles, armour textures, or menu icons.

Moves do nothing when used

Check that Beta APIs is enabled for the world. Scripting addons silently fail to load if experimental scripting support isn't turned on.

A move is unusable even though the tree shows it unlocked

Some moves gate on bending level rather than skill tree state (see the Progression System table). Confirm the player's actual level with the admin panel's Change Level screen.

Known issues

  • Bending armour set bonuses require an exact four-piece match from the same element's armour namespace — mixing in any vanilla or unrelated piece silently disables the effect rather than partially applying it.
  • No-bending zones disable all bending by default unless specific moves are explicitly banned in that zone instead, which can surprise admins expecting an allow-list.
